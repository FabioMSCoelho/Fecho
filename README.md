# Fechô — classes base e debate arquitetural

Projeto acadêmico de Fábio Coelho e Giovana Almeida: troca de objetos por interesse mútuo.
Esta entrega implementa o domínio e as regras em C#, com coleções em memória,
herança, polimorfismo e demonstração por terminal. O banco original está em `database/fecho.sql`.

Requisito de execução: SDK .NET 10. Não exige bibliotecas externas ou MySQL para a demonstração.

```sh
dotnet run --project src/Fecho.Console
dotnet run --project tests/Fecho.Testes
```

A documentação da arquitetura e da apresentação será incluída junto da implementação.
